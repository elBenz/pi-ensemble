# Domain docs

Use single-context domain documentation:

- Read root `CONTEXT.md` before exploring when present.
- Read relevant ADRs under `docs/adr/`.
- Missing files are normal; create them only when domain terms or decisions emerge.
- Use glossary vocabulary consistently.
- Surface conflicts with existing ADRs explicitly.

Expected layout:

```text
/
├── CONTEXT.md
└── docs/adr/
```
