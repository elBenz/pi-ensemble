Target/focus: $@

Build only the context needed to decide or implement this target.

Inspect cheap local facts directly. Delegate substantial independent local investigation to `scout` when useful and available. Add `researcher` only when external evidence can materially change the decision. Give each child a distinct question, exact target, evidence requirements, and concise output contract. If delegation is unavailable or prohibited, gather the evidence directly.

Synthesize known facts, constraints, likely change seam, and open questions. Reuse supplied answers and settled decisions. Ask only about unresolved user-owned decisions that block progress, using `interview` when available or ordinary chat otherwise. Continue independent authorized work while answers are pending; skip an empty interview.

For a standalone context-gathering request, finish with the findings and remaining questions. When this technique is a step within an authorized implementation task, carry those findings forward and continue that task once its blockers are resolved. Context gathering alone does not authorize implementation.
