# Security Policy

## Supported versions

Only the latest released version receives security fixes.

## Reporting a vulnerability

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/elBenz/pi-ensemble/security/advisories/new).

Do not disclose vulnerabilities in public issues, discussions, or pull requests.

A maintainer will acknowledge a report within seven days. Investigation and remediation timelines depend on severity and complexity; no fixed resolution deadline is promised. Please allow time for a fix and coordinated disclosure before publishing details.

Include:

- affected version or commit;
- impact and attack scenario;
- reproduction steps or proof of concept;
- known mitigations;
- any desired disclosure coordination.
